# Canonical Naming Register

Status: initial creative naming pass for M0. These are project-internal fictional names, not a trademark-clearance opinion. Before a public or commercial release, perform a jurisdiction-appropriate name and trademark review.

## Game identity

- Official title: KITEBOUND: ROADS OF VEYRA
- Subtitle: A World Beyond the Apex
- World / region: Veyra Reach
- Fictional setting: a large island region with a working port city, three regional towns, six villages, a volcanic ridge, dry interior flats, coastal wetland, and agricultural basin.

## Fictional manufacturers

| Manufacturer | Identity |
|---|---|
| Ravelin Motor Company | Accessible road cars, compact performance cars, and utility vehicles |
| Caldera Automotive | High-output sports cars and track-focused machines |
| Ternion Works | Rally, gravel, and off-road engineering |
| Orison Coachcraft | Grand touring, roadsters, and heritage-inspired sports cars |
| Veyra Rotary Atelier | Specialist rotary-engine sports cars |

No real-world manufacturer logo or badge is to be copied. The manufacturers above are fictional working names only.

## Naming control

This file is the single source of truth for in-game names. When a name changes, update this register, vehicle data, UI strings, save identifiers where appropriate, event definitions, and all docs in the same change. Save-file identifiers should use stable machine keys rather than visible display names.
